Restricted Editing
------------------
Restrict editing to specific regions of the content. Configure the Pack feature
**Restricted editing**, choose a mode in the feature settings, then drag the toolbar item
into the active toolbar:

* **Standard** — mark editable regions in the content.
* **Restricted** — lock everything outside those regions so editors can only change
  allowed parts.

Use one mode per preset. Only one of these plugins is loaded at a time.
